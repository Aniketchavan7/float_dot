# Changelog

## 0.1.0 — unsigned private beta

- Compact desktop toolbar with explicit capture, voice input, answer card and provider choice.
- Screenshot capture only through the capture button or configured shortcut.
- Optional SearXNG web search with local-model tool planning and visible source buttons.
- AI Settings downloads verified OCR/speech components and local Ollama models with progress and cancellation.
- Onboarding respects text-only use, keeps optional components optional, and displays the real capture shortcut.
- Requested code-only, hints and short-answer formats take priority over default answer headings.
- Clear removes retained source links as well as the current capture and conversation.
- Per-user Windows installer and portable builds, smaller bundled speech runtime, CI checks and SHA-256 release manifests.

This beta has not passed clean-machine, signed-release, live-cloud, physical-device or seven-day pilot qualification. Generated code is not automatically executed or certified correct. See docs/MODULE_IMPLEMENTATION_AUDIT.md and docs/RELEASE_CHECKLIST.md.
