# Float Dot — shipping plan

Updated 9 October 2026. The current delivery plan is [the module-by-module shipping plan](docs/SHIPPING_PLAN.md).

Start with [M00: contracts](docs/modules/M00-contracts.md), then [M01: minimal overlay UI](docs/modules/M01-overlay-ui.md). The plan defines 11 independently owned modules, dependencies, estimates, release gates and a suggested ownership split.

The target is a compact, transparent Windows desktop assistant with explicit screen/voice input and user-selected AI providers. It includes the work needed for installation, reliability and real-user launch validation.
